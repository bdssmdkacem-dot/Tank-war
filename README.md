# Tank War

نسخة 2D Pixel Art مستوحاة من تكوين اللعبة الظاهر في المرجع المرفق.

## التشغيل
افتح `index.html` في المتصفح.

## الموجود حاليا
- خريطة سوداء بأسلوب Pixel Art.
- مبانٍ وجدران وحواجز.
- دبابة اللاعب.
- دبابات أعداء.
- إطلاق نار وتصادمات.
- نقاط وLives وLevel وEnemy counter.
- تحكم WASD / الأسهم.
- أزرار لمس للهاتف.
- إعادة تشغيل بعد Game Over.

## المرحلة التالية
إضافة خرائط متعددة، مؤثرات صوتية، Power-ups، أهداف/علم، انفجارات Pixel Art، شاشة بداية، وحفظ التقدم، ثم تغليف اللعبة كتطبيق Android إذا كان هذا هو الهدف.
